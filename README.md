# Tab Saver

現在のバージョン: **1.0.11**

ChromeとFirefoxのタブをSupabaseに保存し、同じアカウントで別の端末から検索して復元できる拡張機能です。
拡張機能を使えない環境では、[Tab Saver Web](https://nokia215.github.io/tab_ext/dashboard.html)から保存済みセッションを閲覧して再開できます。

## 機能

- 現在のウィンドウ全体や1つのタブを、新規グループまたは既存グループに保存
- グループ名の編集、お気に入り登録、復元後も残す固定設定
- タイトルやURLの検索、端末や保存期間による絞り込み、並び替え
- タブ単位の復元、グループ単位の復元、複数グループの一括復元と削除
- 同じアカウントで保存済みのURLを重複保存しない
- URLリストの貼り付けによるインポートと、クリップボードへのエクスポート
- 別端末での保存、編集、削除、お気に入り変更をダッシュボードに自動反映
- 保存対象から除外するドメインやタイトルの指定

## 基本的な使い方

1. 拡張機能のポップアップで、メールアドレスとパスワードを使ってログインします。
2. 保存先グループを選び、「ウィンドウを保存」または「タブを保存」を押します。
3. 別の端末で同じアカウントにログインし、ダッシュボードまたはTab Saver Webを開きます。
4. 保存済みグループを検索し、タブを1件ずつ、またはグループをまとめて復元します。

保存元のタブは閉じません。
新規グループの名前を空欄にすると、端末と日時に基づく名前を自動設定します。

### 復元と固定グループ

通常グループでは、開く処理に成功したタブを保存一覧から削除します。
復元できなかったタブは残り、すべて復元すると通常のグループも削除します。
繰り返し使うグループは「固定」にすると、復元後も内容を保持できます。
お気に入りのグループは、すべてのタブを復元して空になっても、グループ名とお気に入り状態を保持します。
空のグループは保存先として再利用できます。「グループ削除」を押した場合は、お気に入りや固定のグループも削除します。
「固定」は復元後もタブを保持する設定で、お気に入りとは独立しています。

復元後の削除同期に失敗した場合は、ダッシュボードの「削除の同期を再試行」から再試行できます。
自動同期時にも、未完了の削除同期を再試行します。
タブを連続クリックした場合も、クリックごとに一覧へ即時反映し、復元は受付順に実行します。
復元に失敗したタブは一覧に戻し、処理中の同じタブへの重複クリックは無視します。

### 別端末の変更を自動反映

拡張機能のダッシュボードとTab Saver Webは、ログイン中に次のタイミングで保存済みデータを取得します。

- タブやウィンドウに戻ったとき
- 通信が復帰したとき
- 画面を表示している間、30秒ごと

保存、復元、設定変更、グループ名の編集、日本語入力の変換中は、自動反映を延期します。
取得中に画面を操作した場合は古い取得結果を反映せず、次の同期で再取得します。
検索条件、選択状態、入力途中の内容を保ちながら一覧を更新し、削除されたグループの選択は解除します。

画面には最終同期時刻を表示します。
通信に失敗しても表示中の一覧を残し、次の同期タイミングで再試行します。
すぐに取得したい場合は「更新」を押してください。
非表示中の画面では定期取得を行いません。

端末内にキャッシュがあれば先に一覧を表示し、その後にクラウドの最新データを取得します。
新しいタブの保存には通信が必要で、オフライン保存の送信待ち機能はありません。

### URLリストの入出力

インポート欄に1行につき1つのURLを貼り付けます。
`URL | タイトル` の形式でタイトルも指定でき、新規グループへの保存では空行でグループを分けます。
既存グループを保存先に選んだ場合は、貼り付けたURLをそのグループにまとめて追加します。

```text
https://example.com | Example
https://example.org | Example Org

https://example.net | 別のグループ
```

エクスポートはURLとタブのタイトルをテキストとしてコピーします。
グループ名、固定設定、お気に入り設定は含みません。

## Tab Saver Web

[Tab Saver Webを開く](https://nokia215.github.io/tab_ext/dashboard.html)

拡張機能を使えない環境から、保存済みグループの検索、編集、復元、削除を行えます。
開いているブラウザのタブを自動取得できないため、新たに保存するURLはインポート欄に貼り付けます。
Web版で復元できるURLはHTTPとHTTPSです。
複数のタブを復元する際にポップアップがブロックされた場合は、このサイトのポップアップを許可して再試行してください。

## セットアップ

### アカウントと保存対象

ログインには、接続先Supabaseプロジェクトで作成されたアカウントを使います。
アプリ内にはアカウント登録画面がないため、管理者から共有されたアカウントなどを用意してください。
SupabaseのURLとpublishable keyは[ビルド設定](src/shared/build-config.ts)に含まれています。
`service_role`やsecret keyは含めません。

ブラウザの特殊ページとピン留めタブは保存対象外です。
除外設定では、ドメインやタイトルのルールを1行ずつ入力します。
ルールは大文字と小文字を区別せず、ドメインはホスト名またはURL、タイトルはタイトル文字列への部分一致で判定します。

### ローカルでのビルド

Node.js 24以上とnpmを用意してください。
GitHub ActionsではNode.js 24を使用しています。

```bash
npm install
npm run build
```

Chromeでは`chrome://extensions`でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」から`dist/chrome-mv3/`を選びます。
Firefoxではビルド後に`npm run run:firefox`で開発用ブラウザを起動します。
Windows PowerShellで`npm.ps1`が実行ポリシーによりブロックされる場合は、`npm`の代わりに`npm.cmd`を使ってください。

データベースの初期スキーマは[sql/schema.sql](sql/schema.sql)、追加変更は[増分マイグレーション](supabase/migrations/)にあります。
リンク済みのSupabaseプロジェクトに未適用のマイグレーションを反映するには、Supabase CLIでログインしたうえで次を実行します。

```bash
npm run db:migrate:status  # 適用状況を確認
npm run db:migrate         # 未適用分を適用
```

適用前に内容を確認する場合は`npm run db:migrate:check`を実行します。

## 開発

ダッシュボードの処理は、認証と同期、保存、復元、グループ操作ごとに共通モジュールへ分割しています。
画面イベントから処理を追う入口と各ファイルの責務は、[コード構成](docs/code-structure.md)を参照してください。

```bash
npm run typecheck
npm test              # TSテストのstrict型チェックと回帰テスト
npm run dev:chrome     # Chrome向けの開発
npm run dev:firefox    # Firefox向けの開発
npm run build          # 型チェックと両ブラウザのビルド
npm run build:chrome   # Chromeのみ（型チェックなし）
npm run build:firefox  # Firefoxのみ（型チェックなし）
npm run build:pages    # 型チェックとWeb版のビルド
npm run lint:firefox   # ビルド済みFirefox拡張機能の検証
npm run release        # 両ブラウザのビルドとFirefox配布用ZIPの作成
```

### 出力先と配布

| 対象 | 出力先 |
| --- | --- |
| Chrome拡張機能 | `dist/chrome-mv3/` |
| Firefox拡張機能 | `dist/firefox-mv3/` |
| Firefox配布用ZIP | `dist/firefox-artifacts/tab_saver-<version>.zip` |
| Tab Saver Web | `dist/pages/` |

`npm run release`はローカルでビルドとパッケージ作成を行います。
Web版は、`main`へのプッシュを契機に[GitHub Pagesのワークフロー](.github/workflows/deploy-pages.yml)でビルドしてデプロイします。
